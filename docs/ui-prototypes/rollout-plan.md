# B 單頁儀表板：套用到工坊的計畫

原型：`docs/ui-prototypes/index.html`（B 分頁）。原則是**只改呈現，不改功能邏輯**：所有 `id`、事件接線、`app.js` 的資料流都保留，主要靠新的樣式表加上少量 HTML 結構調整。

## 做法

新增 `public/css/studio-b.css`，放在 `index.html` 所有樣式表的最後面載入（在 `mobile-touch.css` 之後），用它覆蓋舊樣式。舊的 7 個 CSS 先不刪，等新版穩定之後再清理。

## 分階段

| 階段 | 範圍 | 會動到的檔案 | 怎麼驗收 |
|---|---|---|---|
| 1. 色彩與基礎 | 依流程分色的色票（設定藍、角色玫瑰、大綱琥珀、撰寫綠、閱讀紫）、深海軍藍頁首、字體、按鈕和表單樣式；圖示從 emoji 換成 Material Symbols | `studio-b.css`、`index.html`（換字型與圖示） | 淺色和深色模式都截圖檢查 |
| 2. 頁首與進度條 | `#pipeline` 移到深色頁首，每一步的顏色和狀態沿用現有的 `SETUP · —`／`CAST · 0 位`… | `index.html`（移動 header 結構）、`studio-b.css` | 生成過程中進度狀態有正確更新 |
| 3. ①–④ 摘要卡＋右側抽屜 | 4 個 `.config-summary-block` 改成彩色摘要卡；`storyElementsModal`、`advancedSettingsModal`、`specialElementsModal`、`characterSettingsModal` 從置中彈窗改成右側滑出抽屜（只改 CSS，開關邏輯不變） | `studio-b.css` | 四個模組各開一次、改值、關閉，摘要卡會同步更新 |
| 4. 控制台／大綱／手稿 | 創作控制台和預覽大綱並排，統計改成四格彩色指標；手稿正文改成原稿紙：每個字（含標點）佔一格，段首空兩格、段末換行，生成時逐字填進格子；橫排每行格數依寬度調整，直排固定每行 20 格、由右往左；字體大小設定會連動格子大小；章節索引和連貫性紀錄改成新樣式（會動到 `app.js` 正文渲染的地方，複製全文和朗讀仍讀原始文字） | `index.html`（加外層容器）、`studio-b.css` | 開始、繼續、停止、清除都實際生成一段測過 |
| 5. 右側工具列 | 現有「工具」抽屜改成深色直立工具列：模型與用量、快速模板、下載、朗讀、翻書閱讀、書櫃、顯示設定 | `index.html`、`studio-b.css` | 每個工具都點開一次 |
| 6. 書櫃升級 | `bookshelfModal` 改成全螢幕實體書櫃：書放在層板上，頁首顯示統計（本數／萬字／系列數）；**5 種書櫃樣式**（胡桃木、原木北歐、黑鐵工業、古典書房、白色層板，記在 localStorage）；**3 種排列**（現有的封面、書脊，加上新的混排：正面展示、立書、平放疊書、小擺飾；書一律直立，不做傾斜；混排在每次打開書櫃、點「混排」或「重新擺放」時重新隨機，搜尋和排序時維持不變）；書脊 6 種設計（紙標籤、燙金書帶、布面徽章、現代首字、色帶、平裝），長書名自動縮小並維持單行，同一系列各集的尺寸與字級一致；依顏色或造型分組時，用書擋分隔卡標出組別；系列書依集數分成多本書脊，封面加疊書效果和「全 N 集」標記；搜尋、6 種排序、收藏、匯出、匯入都保留；`bookDetail` 改成右側詳情面板，編輯可以換裝幀樣式，刪除改成面板內確認（不再用 `confirm()`）；封面沿用 `book-design.js` 的 `createShelfCover` 和現有 20 種裝幀方向 | `studio-b.css`、`app.js`（只改 `renderBookshelf`、`openBookDetail` 和刪除確認） | 收藏、搜尋、排序、3 種排列、5 種書櫃、詳情、編輯、刪除、匯出、匯入全部走過一次 |
| 7. 手機版與收尾 | 760px 以下：進度條橫向捲動、工具列移到底部、抽屜全寬 | `studio-b.css` | 手機寬度沒有橫向捲動 |

## 每個階段都要做

1. 改檔前先備份：`<原檔名>.bak.<YYYYMMDD-HHMMSS-fff>`
2. 執行 `npm test`
3. 遞增 `public/sw.js` 的 `CACHE_VERSION`（目前是 `v104`）
4. 執行 `node scripts/sync-workshop.js`，同步到根目錄的 GitHub Pages 副本
5. 執行 `npm start` 後實際操作一遍，淺色和深色模式各截圖確認

## 風險

- `styles.css`（6,405 行）和 `layout-polish.css`（3,269 行）的選擇器權重很高，部分覆蓋可能需要用更具體的選擇器；不用 `!important` 硬壓，除非原本的 CSS 已經這樣寫。
- 閱讀站 `reader/` 是獨立 PWA，這次不動。
