## 實作範圍

`public/js/book-design.js` 是無 DOM／網路依賴的裝幀生成器。NFKC 書名種子與各維度子種子控制結構、相容材質、文字布局、主構圖、程序紋樣、邊框與金屬；混合題材取最高兩組關鍵字。未知題材穩定回退，未命名採 ID。外觀不寫入收藏，只新增 `bookshelfView` 偏好，預設封面。

`public/js/app.js` 的書櫃、詳情與造型／顏色排序共用結果。SVG 不包含使用者文字，文字使用 textContent；SVG 裝飾與邊框避開標題區，每個實例的 clip ID 唯一。舊收藏清單的書名／預覽也改為 textContent，修復匯入 HTML 被執行的既有問題。

新 CSS 提供深胡桃木背景、逐列層板、固定工具區與獨立捲動。手機封面兩欄；鍵盤／滑鼠有短暫抽書、傾斜和局部掃光，觸控可點按，減少動態時取消位移及掃光。書本 DOM 與設計快取配合離屏列延後繪製，避免反覆重建所有 SVG。

## 200 本效能

Windows／Chrome headless、1280px，同一台電腦；時間為同步事件＋layout，不包含啟動 Chrome 或網路載入。捲動取 60 個 requestAnimationFrame 間隔。

| 指標 | 修改前 | 修改後最近一次 |
|---|---:|---:|
| 開啟書櫃 | 58.2 ms | 36.0 ms |
| 排序 | 7.1 ms | 10.0 ms |
| 書脊切換 | 原本無此功能 | 5.5 ms |
| 捲動中位數 | 16.7 ms | 16.7 ms |
| 捲動 P95 | 16.9 ms | 17.1 ms |

修改後排序量測前等待兩個畫面，代表使用者可見開啟後再操作；舊基準為同一同步流程直接排序。這不是嚴格微基準或速度保證。多次開發驗證的捲動 P95 約 16.8–33.3 ms，較複雜 SVG 與首次顯示新列仍有繪製成本；未測實體低階手機、iOS Safari 或 Firefox。
